델키 개인정보처리방침

최종 업데이트: 2026년 10월 26일

델키 - 딜리트키, 오른쪽 삭제키(이하 “델키”)는 기존 Android 키보드 위에 Del 버튼을 표시하여 커서 오른쪽 글자 또는 선택된 텍스트를 삭제할 수 있도록 돕는 앱입니다.

1. 수집 및 처리하는 정보

델키는 앱 이용 현황을 파악하고 기능을 개선하기 위해 Google Analytics for Firebase를 사용합니다. 분석 과정에서 다음 정보가 수집 또는 처리될 수 있습니다.

  • Firebase 앱 인스턴스 식별자
  • 앱 실행, 화면 조회 및 DelKey 접근성 서비스 설정 여부와 같은 앱 상호작용
  • 현재 선택된 버튼 색상의 계열과 버튼 아이콘 항목
  • 앱 버전, 운영체제, 기기 모델 등 일반적인 앱·기기 정보
  • 마스킹된 IP 주소에서 파생되는 국가·지역 수준의 대략적인 위치

이름, 이메일 주소, 전화번호, 연락처, 사진, 파일, 입력창에서 사용자가 입력한 텍스트는 분석 정보로 수집하거나 전송하지 않습니다. 정확한 버튼 색상값도 전송하지 않고 색상 계열만 전송합니다.

이전 비공개 테스트 기록

정식 버전 1.12부터 비공개 테스트 참여, 테스트 ID 발급, 실행·삭제 사용 날짜 및 피드백 전송, 리마인드 알림 기능을 제공하지 않습니다. 업데이트 후 앱이 처음 실행되면 이전 테스트의 기기 내 참여 정보와 전송 대기 기록, 예약 작업 및 테스트 알림을 정리합니다. 버튼 설정과 첫 사용 안내 설정은 유지됩니다.

이전 테스트에서 이미 서버에 전송된 기록은 앱 업데이트로 삭제되지 않습니다. 해당 기록은 당시 고지한 방침에 따라 테스트 종료 후 30일 이내에 삭제하는 대상입니다. 삭제 문의는 Google Play에 등록된 개발자 연락처로 요청할 수 있습니다. 이 문구는 서버 기록의 삭제가 완료되었다는 의미가 아닙니다.

2. 접근성 서비스 사용

델키는 기존 키보드 위에 Del 버튼을 표시하고 현재 입력창에서 삭제 동작을 수행하기 위해 Android 접근성 서비스를 사용합니다.

접근성 서비스는 키보드 표시 상태, 키보드 위치, 현재 입력창 연결 여부를 확인하는 데 사용됩니다. 사용자가 입력한 텍스트를 저장하거나 외부로 전송하지 않습니다.

3. 기기에 저장되는 정보

델키는 일반 앱 동작을 위해 다음 설정값을 사용자의 기기 안에 저장합니다.

  • Del 버튼 사용 여부
  • 버튼 위치
  • 버튼 크기
  • 버튼 색상
  • 버튼 아이콘 설정
  • 기능별 광고 표시 및 해제 완료 여부

버튼 위치·크기와 정확한 색상값은 기기 내부에만 저장됩니다. 분석을 위해 접근성 서비스 설정 상태, 델키 활성화 상태, 버튼 색상 계열, 선택한 아이콘 항목 및 기능별 광고 요청·표시·시청 완료·닫기·해제·실패 여부가 Google Analytics for Firebase로 전송될 수 있습니다.

4. 분석 서비스

Google Analytics for Firebase는 위 정보를 앱 사용 통계 작성과 기능 개선을 위한 분석 목적으로 처리합니다. 분석 데이터는 전송 중 암호화되며, 이벤트 및 사용자 수준 데이터는 Google Analytics 프로젝트에 설정된 보관 기간에 따라 처리됩니다.

델키는 앱에서 Google Analytics의 광고 ID 수집과 광고 개인화 신호를 비활성화합니다.

5. 광고

광고 연동 버전은 Google AdMob(Google Mobile Ads SDK)과 User Messaging Platform(UMP)을 사용합니다. 델키 사용, 버튼 색상, 버튼 아이콘 기능에 각각 보상형 광고를 연결합니다. 사용자가 해당 기능의 안내에서 ‘확인’을 선택하면 광고를 요청합니다. 광고가 실제 표시된 뒤 닫히면 시청 완료 여부와 관계없이 해당 기능을 해제하며, 중간에 닫아도 해제합니다. ‘나중에’를 선택하거나 광고를 불러오지 못하거나 표시하지 못하면 기능을 해제하지 않습니다. 광고 길이와 닫기 버튼은 광고 소재가 결정합니다.

광고 제공, 측정 및 부정 사용 방지를 위해 Google은 IP 주소와 여기서 추정한 대략적 위치, 광고·앱 상호작용, 성능·진단 정보, 앱 세트 ID 등 기기 식별자를 처리할 수 있습니다. 현재 앱은 Android 광고 ID 및 AdServices 광고 ID·Attribution·Topics 관련 권한을 제거합니다. 이 권한 제거가 모든 기기 식별자나 광고 관련 정보 처리를 없앤다는 뜻은 아닙니다. 입력한 문장과 삭제한 글자를 광고 SDK에 전달하지 않습니다.

광고 요청 전에 UMP로 필요한 동의 상태를 확인합니다. 필요한 경우 동의 양식을 표시하며, 제공이 필요한 환경에서는 앱 안에 광고 개인정보 설정 메뉴를 표시합니다. 동의 상태를 확인할 수 없거나 광고 요청이 허용되지 않으면 광고를 요청하지 않고 해당 해제를 보류합니다. 기능별 광고 표시 및 해제 기록은 기기에 저장하며, 재실행·업데이트·‘모든 설정 초기화’ 후에도 유지합니다. 표시 중 앱 프로세스가 종료된 경우 다음 실행에서 표시 기록으로 해당 기능의 해제를 복구합니다. 앱 삭제·데이터 초기화·다른 기기에서는 권한을 복원하지 않습니다.

6. 외부 서비스 제공자

Google은 Google Analytics for Firebase, Firebase Authentication, Cloud Firestore, AdMob 및 UMP를 제공하며 각 서비스에 필요한 분석·광고·동의 정보를 처리합니다. 델키는 사용자의 입력 내용을 판매하거나 광고 SDK에 전달하지 않습니다.

7. 아동 개인정보

델키는 고의로 아동의 개인정보를 수집하지 않습니다. 앱이 어린이를 포함한 사용자를 대상으로 제공되는 경우, 광고와 데이터 처리는 Google Play 가족 정책 및 관련 법령을 준수하도록 관리합니다.

8. 보안 및 데이터 관리

델키는 입력 내용을 저장하거나 전송하지 않습니다. 분석 데이터는 암호화된 연결을 통해 전송됩니다. 앱 데이터 삭제 또는 앱 제거 시 해당 설치의 로컬 설정과 앱 인스턴스가 삭제되며, 기존 집계 데이터는 설정된 보관 기간에 따라 처리됩니다.

10. 변경

본 개인정보처리방침은 앱 기능, 광고 SDK, 법령 또는 정책 변경에 따라 수정될 수 있습니다. 변경 시 이 페이지의 최종 업데이트 날짜를 갱신합니다.

초대 코드 등록

초대 코드를 등록하면 델키 사용·버튼 색상·버튼 아이콘을 광고 없이 사용할 수 있습니다. 등록을 시작할 때 Firebase Authentication의 익명 설치 식별자를 사용하며, 코드의 SHA-256 해시·사용 여부·등록 식별자·서버 등록 시각과 설치별 해제 권한을 Cloud Firestore에 저장합니다. 코드 원문은 Firestore나 Analytics에 보내지 않습니다. 이 기록은 기능 제공과 코드 중복 사용 방지를 위해 처리하며 광고 타기팅과 분석 이벤트에 연결하지 않습니다. 등록에는 인터넷이 필요하고, 등록 후 권한은 기기에 저장됩니다. 재실행·업데이트·모든 설정 초기화 후에도 유지되지만 앱 삭제·데이터 초기화·다른 기기에는 복원되지 않습니다. 등록 기록에는 자동 만료가 없으며 초대 프로그램 운영과 중복 사용 방지에 필요한 동안 보관합니다. 삭제 요청은 Google Play에 게시된 개발자 연락처로 문의해 주세요.
